# Gestión de Inventarios

## Tipos

- Inventario físico
- Inventario digital
- Inventario temporal
- Inventario en tránsito
- Inventario cíclico

## Métodos

FIFO

First In First Out.

FEFO

First Expired First Out.

## Conteos

Se realizan:

- Diario
- Semanal
- Mensual

## Ajustes

Todo ajuste requiere autorización del supervisor.

## Productos dañados

Los productos dañados deben registrarse inmediatamente en el WMS.
